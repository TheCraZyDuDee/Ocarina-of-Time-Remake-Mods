# Frame rate and performance mods

These are **separate alternatives** for the same game's frame-rate controller. Install only one at a time.

| Mod | Behavior | Testing status |
| --- | --- | --- |
| [Fixed 30 FPS](fixed-30/README.md) | Native game-engine 30 FPS lock. | Normal-speed gameplay confirmed on the E0F3 build. |
| [Native Adaptive FPS](native-adaptive/README.md) | Native discrete 20/30/60 FPS options. | 20 FPS behavior reported working; higher modes unverified. |
| [Variable-average FPS](variable-average/README.md) | Attempts intermediate averages by mixing native intervals. | Experimental, not gameplay-tested. |

## Compatibility

All three ZIPs include patches for both known Ocarina of Time remake `main` build IDs:

- `E0F3CCFAF50065AE4EA01EB5AEB13B1A45DA3348` — labeled update v131072 in [Orchid's source](https://github.com/MythosOfs/Orchid/blob/main/src/core/file_sys/patch_manager.cpp).
- `33FA6C2C23848282A77E8B88A0A93F4887C55920` — labeled base v65536 in the same source.

Game title ID: `0400486024DEC000`. Your emulator chooses the matching patch based on the **loaded executable**, not the ZIP name. Other builds are unsupported.

## Installation

1. Open the individual mod's README and download its ZIP.
2. Import the ZIP through the emulator's mod manager, or extract the contained `0400486024DEC000/` directory into its `load/` folder.
3. Disable other FPS mods and Orchid's built-in 30 FPS patch. Set emulator speed to **100%** and turn off frame generation.
4. Restart the game. If the change does not appear, check the emulator log for `Applying IPS patch from mod` and confirm the loaded build ID.

Back up your saves before trying experimental options. An FPS counter alone does not prove normal simulation speed or correct physics.

## Source and verification

The patches are generated by [`build.py`](build.py) using Python's standard library. Run from the repository root:

```sh
python3 mods/fps/build.py --output-dir dist
python3 -m unittest discover -s tests -v
```
