# Mod catalog

Mods are grouped by **what they change**, so new gameplay, graphics or quality-of-life categories can be added later without mixing them with FPS mods.

| Category | Available mods |
| --- | --- |
| [Frame rate and performance](fps/README.md) | Fixed 30 FPS, Native Adaptive FPS, Variable-average FPS |

For details, installation, compatibility and download links, open a category and then a mod's README.

New categories should use `mods/<category>/<mod-name>/README.md`. See the [contribution guide](../docs/DEVELOPMENT.md).
