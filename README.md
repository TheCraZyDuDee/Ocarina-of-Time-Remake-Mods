# Ocarina of Time Remake Mods

A collection of mods for *The Legend of Zelda: Ocarina of Time* on Nintendo Switch 2.

Pick a mod below for details and installation instructions. Downloads contain IPS32 patches only; you'll need your own game files and a compatible emulator.

## AI disclaimer

These mods are developed almost entirely using AI, including the code and documentation. If you don't trust AI-generated code or dislike using AI for development, please skip this project. Use the mods only if you're comfortable with that.

## Mods

| Mod | What it does | Supported builds | Download |
| --- | --- | --- | --- |
| [True Dynamic FPS](mods/fps/true-dynamic/README.md) | Adjusts game timing as the frame rate changes. Experimental. | E0F3 only | [ZIP](releases/oot-true-dynamic-e0f3.zip?raw=true) |
| [Fixed 30 FPS](mods/fps/fixed-30/README.md) | Locks the game's frame rate to 30 FPS. | E0F3, 33FA | [ZIP](releases/oot-fixed-30-both-builds.zip?raw=true) |
| [Native Adaptive FPS](mods/fps/native-adaptive/README.md) | Lets the game switch between 20, 30 and 60 FPS. Experimental. | E0F3, 33FA | [ZIP](releases/oot-adaptive-both-builds.zip?raw=true) |

Use one FPS mod at a time. See [FPS setup and compatibility](mods/fps/README.md) if you're unsure which build you have.
